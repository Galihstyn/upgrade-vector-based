## 2024-06-03 - Optimize Object Bounding Box Calculation
**Learning:** In a canvas or diagram application, bounding box calculations are extremely hot paths. The pattern `Math.min(...points.map(p => p.x))` calculates bounding boxes inefficiently. It creates an intermediate array (`map`), expands the array into arguments (`...`), and does this four times (minX, maxX, minY, maxY). This results in multiple array allocations and a massive call stack size if the points array is very large.
**Action:** Replace `Math.min(...points.map(...))` pattern with a fast, single pass `for` loop `getPointsBounds(points)` utility that iterates the array once to calculate minX, maxX, minY, maxY concurrently. This cuts redundant O(N) loops and entirely avoids array allocations and spread operator stack exhaustion limits.
