## 2024-05-24 - Lazy Initialization of Expensive useRefs in Hot Paths
**Learning:** Using `useRef(expensiveFunction())` in a React hot path (like the root App component that triggers many downstream re-renders) causes the expensive function to evaluate on every single render cycle, even though the returned value is only used during the initial mount. In this codebase, `getThemeBootstrap()`, `safeClone()`, and `buildProjectStorageKey()` were being eagerly evaluated on every render of the main canvas editor component.
**Action:** Always use the lazy initialization pattern for expensive operations in `useRef`: `const ref = useRef(null); if (ref.current === null) { ref.current = expensiveFunction(); }`. This ensures the expensive work is only done once per component lifecycle.
