## 2025-06-06 - Avoid useRef(expensiveFunction())
**Learning:** In React, `useRef(initialValue)` evaluates the `initialValue` argument on every single render, even though the returned ref is only updated on the first render. Passing expensive functions (like `getThemeBootstrap()`, `safeClone()`, or deep object merges) directly into `useRef` causes significant and unnecessary CPU overhead during React component re-renders.
**Action:** Use a lazy initialization pattern with an explicit boolean guard (`const isInitialized = useRef(false); if (!isInitialized.current) { ref.current = expensiveFunction(); isInitialized.current = true; }`) to ensure expensive computations run exactly once. Do not rely solely on checking if the ref itself is null, as the function might legitimately return null.
