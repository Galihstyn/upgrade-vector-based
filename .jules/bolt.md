## 2025-02-18 - Avoid array allocations and redundant trig in hot loops
**Learning:** In performance-critical sections, such as the character mapping loop in `getWarpMetrics` (`app32825_FIXED.jsx`), chaining `.map()` and `.forEach()` to compute and iterate over intermediate arrays (like bounding box corners) creates significant garbage collection pressure. Additionally, recalculating `Math.cos()` and `Math.sin()` multiple times for the same angle inside the loop wastes CPU cycles.
**Action:** When computing bounds or transformations in hot loops, hoist loop-invariant values (e.g., trigonometric calculations) into variables. Calculate coordinate transformations inline rather than allocating temporary point arrays or object literals to significantly improve execution time and memory efficiency.
