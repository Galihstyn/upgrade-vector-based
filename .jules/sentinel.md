## 2024-06-12 - Missing URL Encoding in Client-Side Navigation
**Vulnerability:** The application constructs client-side navigation URLs using unsanitized string values derived from configuration or DOM attributes (`window.location.href = \`/products/\${sourceHandle}\``).
**Learning:** While React automatically sanitizes variables when rendering JSX to protect against XSS, it does not provide any protection when modifying the `window.location.href` directly. String interpolation used to construct redirect URLs or API paths completely bypasses React's protections, leading to potential Open Redirect or Path Traversal vulnerabilities if the inputs contain directory traversal sequences (`../`) or absolute URLs (`//evil.com`).
**Prevention:** Always explicitly sanitize user-controlled or externally-sourced strings using `encodeURIComponent()` before interpolating them into client-side navigation paths (e.g., `window.location.href = \`/products/\${encodeURIComponent(sourceHandle)}\``).
