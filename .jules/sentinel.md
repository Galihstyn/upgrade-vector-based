## 2024-05-24 - Path Traversal / Open Redirect via Unsanitized Product Handle
**Vulnerability:** In `handleBackNavigation` of `app32825_FIXED.jsx`, the `productHandle` extracted from `themeBootstrapRef.current` was trimmed but not URL-encoded before being interpolated directly into a path (`/products/${sourceHandle}`). If an attacker provided a crafted `productHandle` containing `../` sequences, they could escape the `/products/` directory and potentially trigger XSS via the `javascript:` pseudo-protocol or redirect users to malicious endpoints when the URL is assigned to `window.location.href`.
**Learning:** Even internal routing paths constructed on the client side are vulnerable if they include user-controlled parameters. The `productHandle` originates from the bootstrap configuration, which can be influenced by URL parameters or dataset attributes. Relying solely on `.trim()` is insufficient for security.
**Prevention:** Always apply `encodeURIComponent()` to any dynamically generated path segments or URL parameters before appending them to navigation URLs, especially those passed to sink like `window.location.href`, to neutralize path traversal and pseudo-protocol execution.
