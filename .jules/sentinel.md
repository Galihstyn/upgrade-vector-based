## 2024-05-31 - [HIGH] Fix open redirect and path traversal in routing
**Vulnerability:** The `handleBackNavigation` function embedded the `sourceHandle` into a URL without encoding, leading to potential path traversal, and improperly trusted `document.referrer` by directly setting `window.location.href`, causing an open redirect via `javascript:` URIs (which return a `"null"` origin) or protocol-relative URLs (`//`).
**Learning:** Checking that `origin === window.location.origin` is insufficient if the browser evaluates the origin of a data/javascript URI as `"null"`. Additionally, relying solely on `referrerUrl.href` enables protocol-relative URL injection.
**Prevention:** Always sanitize dynamically embedded URL parameters using `encodeURIComponent`. For relative redirects from `document.referrer`, construct the target using exclusively path components (`pathname + search + hash`), explicitly check for `"null"` origin, and enforce strict prefix validation (`startsWith('/') && !startsWith('//')`).
