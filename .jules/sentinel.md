## 2024-05-18 - [HIGH] Fix Open Redirect & Path Traversal in handleBackNavigation

**Vulnerability:** The `handleBackNavigation` component in `app32825_FIXED.jsx` was vulnerable to path traversal through `sourceHandle` parameter insertion into `/products/${sourceHandle}`, and open redirects by parsing `document.referrer` directly via `window.location.href = referrerUrl.href;`. An attacker could spoof the referrer to navigate users to arbitrary malicious URLs.
**Learning:** Incomplete validation of input paths and lack of constraints on origin redirects enabled both path traversal issues and potential open redirects. Using absolute URLs mapped from untrusted referrer inputs often triggers unexpected internal forwarding flaws in React apps without proper sanitization.
**Prevention:** Always encode user inputs interpolating internal URL paths using `encodeURIComponent()`. Only redirect via `window.location.href` to relative internal paths (e.g. `referrerUrl.pathname + referrerUrl.search + referrerUrl.hash`) explicitly ensuring they do not begin with double slashes `//` preventing unintended external protocol-relative routing, and strictly validate the matching origin dynamically against `window.location.origin` enforcing it's never `'null'`.
