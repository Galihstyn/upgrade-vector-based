## 2024-04-10 - [Accessibility] Added aria-labels and focus-visible rings to Utility Panel buttons\n**Learning:** Utility buttons (Undo, Redo, Zoom) using lucide-react icons were not keyboard accessible or screen reader friendly.\n**Action:** When adding or modifying icon-only buttons, always include an `aria-label` and `focus-visible` styling (e.g., `focus-visible:ring-2 focus-visible:ring-indigo-500 focus-visible:outline-none`) to ensure users can navigate and understand the purpose of each button via keyboard and screen readers.
