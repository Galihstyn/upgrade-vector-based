## 2024-05-24 - Accessibility Enhancements for Top Utility Toolbar
**Learning:** Icon-only buttons for critical editing tools like Undo, Redo, and Zoom are commonly implemented without appropriate `aria-label`s, rendering them opaque to screen reader users. Additionally, when using SVG components directly within buttons, screen readers may redundantly announce the SVG content unless `aria-hidden="true"` is applied to the SVG. Dynamically changing text, such as a zoom percentage display, requires `aria-live="polite"` so screen readers proactively read updates when the value changes via adjacent controls.
**Action:** When implementing toolbars or icon-heavy interfaces, proactively inspect the components to ensure every interactive element is either natively semantic or appropriately labeled. Add `aria-live` to spans or divs where adjacent buttons directly manipulate their text content.
