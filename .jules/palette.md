## 2024-05-24 - Accessibility on Canvas Utility Panel
**Learning:** Icon-only buttons (like Undo, Redo, Zoom) and dynamic text elements require both `aria-labels` and visual focus states to be accessible. Screen readers may read the icon name out loud alongside the label, so adding `aria-hidden="true"` to the inner SVG prevents redundant announcements. Additionally, dynamic text changes (like zoom percentage) need `role="status"` and `aria-live="polite"` so screen readers proactively announce the update without interrupting the user.
**Action:** When adding or updating icon-only buttons, always include `aria-label`, `focus-visible:*` classes, and `aria-hidden="true"` on the SVG. Apply `role="status"` and `aria-live` to elements that update dynamically in response to user actions. Always be careful to not include build artifacts or log files when preparing a commit.
